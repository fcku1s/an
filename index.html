🤖 安卓客户端配置教程

按照下面步骤操作，即可完成 Karing 安卓客户端配置。

📦 安卓客户端下载
下载 Karing 安卓版
💡 下载完成后打开 APK 进行安装。如果系统提示允许安装未知来源应用，请按照系统提示允许安装。

第一步：同意隐私协议

  1. 打开 Karing App。
  2. 首次打开会出现隐私协议页面。
  3. 点击「接受并继续」。

第二步：选择语言

  1. 在语言列表中找到「简体中文」。
  2. 选择「简体中文」。
  3. 点击右上角「下一步」。

第三步：TV 设置

  1. 进入 TV 设置页面。
  2. 这里不需要开启任何开关。
  3. 保持默认设置。
  4. 点击右上角「下一步」。

第四步：选择国家与地区

  1. 在国家或地区列表中找到「CN 中国」。
  2. 选择「CN 中国」。
  3. 点击右上角「下一步」。
⚠️ 请按照你实际所在的国家或地区进行选择，否则可能影响规则分流。

第五步：预置分流组设置

  1. 进入预置分流组设置页面。
  2. 按照默认选项即可。
  3. 无需额外修改。
  4. 点击右上角「下一步」。

第六步：完成初始设置

  1. 保持「新手模式」开启。
  2. 点击右上角「完成」。

第七步：进入添加配置页面

  1. 进入 Karing 首页。
  2. 找到「添加配置」。
  3. 进入添加配置页面。
  4. 点击「添加配置链接」。

第八步：打开会员中心，导入订阅

  1. 打开会员中心：dankewed.com
  2. 登录你的会员账号。
  3. 点击底部「仪表盘」。
  4. 找到你的套餐信息。
  5. 点击橙色「导入订阅」按钮。

第九步：复制订阅地址

  1. 在导入订阅窗口中找到 Android 分类。
  2. 点击「复制订阅地址」。
  3. 订阅地址会自动复制到手机剪贴板。
💡 复制完成后不要修改订阅地址，直接回到 Karing App。

第十步：粘贴订阅地址

  1. 回到 Karing。
  2. 进入「配置链接/内容」输入框。
  3. 长按输入框，点击「粘贴」。
  4. 在「备注」栏填写一个容易识别的名称。
  5. 确认订阅地址无误。
  6. 点击右上角「✓」完成添加。

第十一步：进入服务器选择

  1. 返回 Karing 首页。
  2. 找到当前的「自动选择」区域。
  3. 点击「自动选择」进入服务器选择页面。

第十二步：选择刚才导入的订阅

  1. 进入「选择服务器」页面。
  2. 找到刚才添加的订阅分组。
  3. 一般会显示为你之前填写的备注名称。
  4. 点击该分组展开节点。

第十三步：测速并选择节点

  1. 点击右上角的闪电 ⚡ 图标。
  2. 等待所有节点完成测速。
  3. 查看各节点延迟。
  4. 一般来说延迟数值越低，响应速度越快。
  5. 选择一个延迟较低且稳定的节点。
💡 如果某个节点显示超时或无法测速，可以更换其他节点。

第十四步：完成，开始使用 🎉

  1. 返回 Karing 首页。
  2. 点击底部圆形开关。
  3. 首次启动时，如果 Android 弹出 VPN 权限请求，请点击「允许」。
  4. 连接成功后即可使用。
✅ 开启成功后，系统状态栏通常会出现 VPN 或钥匙形状的连接提示。
